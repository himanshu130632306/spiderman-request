# Music Files

Add your Spider-Man MP3 file here named: `spiderman.mp3`

The music player in the website will automatically pick it up from `/music/spiderman.mp3`.

## Steps:
1. Place your MP3 file in this folder as `spiderman.mp3`
2. The background music player will load and play it automatically
3. Users can control it with the floating music player in the bottom-right corner

## For GitHub deployment:
- Make sure the MP3 file is committed to the repository
- GitHub Pages will serve it automatically

## Note on YouTube audio:
The YouTube link (https://youtu.be/7ZIs2sAeKiE) cannot be directly embedded due to YouTube's terms of service.
To use this audio:
1. Download the audio from YouTube (using a legal YouTube-to-MP3 converter)
2. Save it as `spiderman.mp3` in this folder
